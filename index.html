    How these tools work

    LSB steganography changes the last bit of the red, green and blue values of pixels to store a 32-bit length followed by your UTF-8 message. The change is far too small to see, but it is not encryption, so encrypt sensitive text before hiding it.

    Hashes are one-way fingerprints of data. SHA-256 and SHA-512 are widely used for integrity checks; SHA-1 is shown for legacy comparison only.

    Password strength is estimated from length and character variety, with penalties for common words, repeats and sequences. Crack time assumes an attacker testing 10 billion guesses per second against a fast hash. It is an estimate, not a guarantee. Use a password manager and unique passwords.
